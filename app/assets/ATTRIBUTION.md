# Chess-piece artwork

The twelve classic chess-piece designs are by **Colin M. L. Burnett (Cburnett)**,
with subsequent contributors credited in each Wikimedia Commons file history.
ChessLab uses the **Creative Commons Attribution-ShareAlike 3.0 Unported** license
offered by each source file. This license applies to the artwork, including the
PNG conversions; it does not assign a license to ChessLab's application code.

Unmodified SVG sources are retained in `source/`. The only changes for `pieces/`
are uniformly scaling the SVG vectors and rendering transparent 256 × 256 PNGs.
No artistic changes are intended. See `tools/prepare_assets.py` for the development
conversion process. The application uses the checked-in PNGs offline.
